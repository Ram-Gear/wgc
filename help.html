Web Gear Calc help

Web Gear Calc is a single-page browser rebuild of GCP3 (Gear Calculation Program) by Scott Atkinson, Ash Gear & Supply Corp., Novi, MI. It designs and checks spur, helical, worm, spline, rack and bevel gears, and works backwards from measurements of a worn or broken gear to its likely design. It runs entirely in your browser, either at ram-gear.github.io/wgc or from the offline file WebGearCalc.html. Nothing you enter is sent anywhere.

Basics Ask Grok about this

  • The Main Menu lists the screens. Click a tile or press 1–9. Click the icon at the top left to come back. Ask Grok about this
  • Use English (in) / Metric (mm) at the top right to switch units. Ask Grok about this
  • Values recalculate as you type. A blank field shows the computed value. Fields you typed are shown in bold blue. Ask Grok about this
  • Keys on a screen: Enter moves to the next field, Esc clears the field and Ctrl+P prints. Clear all empties the screen. Ask Grok about this
  • Each screen has Print, Save .TXT (a plain-text printout; the file name is in the box beside it) and Copy (copies the printout text). Ask Grok about this

Screens Ask Grok about this

1 · External Spur Gears (EXT) Ask Grok about this
Spur gears and involute splines: pitch (circular, diametral or module), pressure angle, teeth, diameters, depths and tooth thickness. Shows measurement over wires (pins), span, TIF and shaper data, and the "Shaper Ex." exact shaper-cut root. Choose the depth system (for example Hob 2.1571) above the table. The "Diff.Produced Using Std." column shows how your entries differ from standard.
2 · Internal Spur Gears (INT) Ask Grok about this
Internal gears and splines, with measurement under wires (MUW), space width and shaper data.
3 · External Helical Gears (HELIX) Ask Grok about this
Helical gears in the transverse and normal planes, with MOW, span and lead.
4 · Internal Helical Gears (INHEL) Ask Grok about this
Internal helical gears, measured under balls.
5 · Worm Gears (WORM) Ask Grok about this
A worm and gear set, with operating values at a given center distance.
6 · Rack / Rackworm (RACK) Ask Grok about this
Racks and rack-type worms: tooth form and measurement over a wire at the addendum.
7 · Straight-Sided Splines (SPL) Ask Grok about this
Parallel-sided splines, including the tool point width.
8 · Bevel Gears (BEVEL) Ask Grok about this
Straight, spiral, Zerol and hypoid bevel gears (hypoid geometry is approximate), with a dimensioned mesh sketch and an AGMA 2003-style rating.
9 · Two-Gear Mesh (MESH) Ask Grok about this
Checks an EXT or HELIX pair in mesh. Results are in three columns: Gear 1, the pair, and Gear 2. The center column gives the tight-mesh (zero-backlash) center distance, the change from the center you entered, the operating pressure angle, backlash, and contact, overlap and total ratios. Each gear's column gives its diameters, thickness, TIF, tip clearance, undercut and interference flags. A mesh drawing can be drawn at either the tight or the entered center distance.
Measure / Identify (reverse engineering) Ask Grok about this
Available for EXT, INT, HELIX, INHEL, WORM, RACK, SPL and BEVEL, from the Main Menu or the green Measure / Identify button on a screen. Enter what you can measure (blank means not measured) and it ranks candidate standard pitches and pressure angles with a confidence. Two spans over different numbers of teeth work best, because their difference gives the base pitch whatever the flank wear. Two pin sizes also work. OD and root are treated as possibly worn. You can limit the pitch families, pressure angles and (where relevant) the standard plane or bevel system, and set your measurement uncertainty.
Saved gears (profiles) Ask Grok about this
Save gear... and Load gear... on EXT and HELIX store everything you entered under a name. The Saved gears (profiles)... button on the Main Menu opens the manager: open, rename, delete or export each gear, Export all (JSON), and import a JSON file.
Drawings Ask Grok about this
Every screen draws the tooth profile from the current values. BEVEL adds a dimensioned mesh sketch and MESH adds the two-gear mesh drawing.

Common tasks Ask Grok about this

Design a spur gear and check it over pins Ask Grok about this

  1. Open 1 External Spur Gears and choose English or Metric. Ask Grok about this
  2. Enter one pitch (Circular, Diametral or Module, lines 1–3), the Pressure Angle (line 4) and the Number of teeth (line 5). Ask Grok about this
  3. Set the depth system, and enter any diameters or tooth thickness you need. Leave the rest blank to see standard values. Ask Grok about this
  4. Read the measurement over wire and the wire size from the table, then compare with your pin reading. Ask Grok about this

Identify a worn gear from two spans Ask Grok about this

  1. Count the teeth. Measure span over k1 teeth and over a different k2 teeth (for example 3 and 4). Ask Grok about this
  2. Open Measure / Identify for the gear type (for example EXT). Ask Grok about this
  3. Enter the tooth count, Span 1: teeth k1 and its measurement, and Span 2: teeth k2 and its measurement. Add OD, root or pins if you have them. Ask Grok about this
  4. Check the ranked candidates. The top one shows the best-matching standard pitch and pressure angle with its confidence. Ask Grok about this

Save two gears and mesh them for center distance Ask Grok about this

  1. Enter the first gear on EXT (or HELIX). Click Save gear... and give it a name such as "Gear A". For helical gears, set the hand of helix. You are warned before an existing name is overwritten. Ask Grok about this
  2. Enter the mating gear and save it as "Gear B". Ask Grok about this
  3. Open 9 Two-Gear Mesh. In the Saved gears box, choose Load Gear 1 from profile and Load Gear 2 from profile. Ask Grok about this
  4. Read the tight-mesh center distance at the top of the center column. To see backlash and clearance at your actual center, enter it as the center distance to check. Ask Grok about this
  5. Alternatively, use Mesh with mate on EXT or HELIX to carry the current gear into MESH, or type both gears in by hand. Ask Grok about this

Print or save a .TXT Ask Grok about this

  1. On any screen click Print (or press Ctrl+P) for a printer-friendly page. The buttons and the colored background are left out. Ask Grok about this
  2. Or edit the file name beside Save .TXT and click it to download the plain-text printout. Copy puts the same text on the clipboard. Ask Grok about this

Export and import profiles Ask Grok about this

  1. On the Main Menu click Saved gears (profiles).... Ask Grok about this
  2. Click Export all (JSON) (or Export on one gear) to download a .json file. This is your backup. Ask Grok about this
  3. In the other copy of the app (website or offline file), open the same manager and import the .json file. If a name already exists you can choose Keep both, Replace mine or Skip those. Ask Grok about this

Troubleshooting Ask Grok about this

A saved gear isn't in the MESH list Ask Grok about this
MESH only lists gears that can mesh with the gear already chosen: same pitch, same pressure angle, same helix angle, and opposite hand for helical. Click the "hidden" count under the pickers to see each hidden gear and the value that doesn't match. Open that gear on EXT or HELIX, correct it and save it again. Only gears saved from EXT and HELIX can be used in MESH.
A mismatch message blocks the MESH result Ask Grok about this
The message names the value that differs and shows both values, for example "Pressure angle doesn't match: Gear 1 20.000°, Gear 2 25.000°". Correct the entry, choose another gear, or (for helical gears) set opposite hands.
My saved gears are missing Ask Grok about this
Gears are saved in your browser's storage. The website and the offline WebGearCalc.html file keep separate stores, and so does each browser and computer. Use Export all (JSON) in one copy and import the file in the other. Clearing your browser data also deletes saved gears, so keep an exported backup.
The printout Ask Grok about this
Use the app's Print button rather than printing the page another way. If lines wrap, choose portrait and 100% scale in the print dialog, or use Save .TXT, which is 80 columns wide.
Browser Ask Grok about this
Use a current Chrome, Edge or Firefox. If the page looks wrong, reload it (Ctrl+F5 on the website). The offline file works from a local folder with no internet connection.
